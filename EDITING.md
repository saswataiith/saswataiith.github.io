# Editing your academic website

This redesign keeps the repository's Jekyll / GitHub Pages structure. It does not use Sites or a proprietary site builder.

## Common changes

| Change | Edit |
|---|---|
| Homepage biography and research introduction | `_pages/about.md` |
| Research descriptions | `_pages/research.html` |
| Academic CV | `_pages/cv.md` |
| Teaching | `_pages/teaching.html` |
| Add a publication | `_data/selected_publications.yml` |
| Add a resource | `_data/mesoscale_resources.yml` |
| Navigation links | `_data/navigation.yml` |
| Colors, layout and fonts | `assets/css/scholar.css` |
| Shared header, footer and contact information | `_layouts/scholar.html` |

The two data files use JSON syntax, which is valid YAML. Copy an existing record, edit it and retain commas between records. Resource categories must match the visible filter choices: Software, Tutorial, Documentation, Video or Course material.

## Add a resource

Add a record to `_data/mesoscale_resources.yml` with `title`, `category`, `topic`, `description`, `url`, `label` and `level`. Use a full HTTPS link for an external resource or a leading-slash path for a local resource. For a file you have permission to share publicly, upload it under `files/mesoscale/` and link to it. Do not upload copyrighted textbook PDFs without permission.

## Preview and publish

Use the existing Gemfile: `bundle install`, then `bundle exec jekyll serve`. Open the address printed by Jekyll. Changes become public when merged into the branch configured for GitHub Pages. Review a branch or pull request first.

## The Fun in Science: photos, questions and discussion

Edit `_data/personal_notebook.yml`. Both lists begin empty, so no personal photos or opinions are invented. Add photos under `assets/images/notebook/`. Example structure (replace all example text and image paths before adding):

```yaml
photos:
  - image: /assets/images/notebook/my-photo.jpg
    alt: A short description of what the photo shows
    caption: Your caption or story
notes:
  - date: "2026-09-21"
    title: Your reflection's title
    discussion_url: "" # Optional URL of a real discussion thread
    body: |
      Write your reflection here. Markdown paragraphs and links are supported.
```

## LaTeX equations

The shared layout loads locally bundled MathJax 3.2.2 with TeX-style SVG glyphs, including bold tensor symbols. Use `\( ... \)` for inline math and `\[ ... \]` for display math; aligned derivations can use `\begin{aligned} ... \end{aligned}`. Keep code inside `<pre><code>` so it is not typeset. Formula panels scroll horizontally on small screens. The main equations in the thesis formulation, appendices, theorems and all worked examples have been converted to LaTeX. The renderer and its license are in `assets/vendor/mathjax/`; no external math service is needed.

Each science note may include `discussion_url` to link to a real discussion thread. No comment backend is configured yet; the page must not claim to store replies.

The photo-section bicontinuity feature is in `_pages/notebook.html`, with measured data in `assets/examples/bicontinuity/`. Reproduce it with `files/mesoscale/examples/bicontinuity.py` (NumPy and Pillow). It compares identical-seed chemical spinodal runs at mean 0.5 and 0.4; four-neighbor periodic connectivity and winding are tested at three thresholds.
