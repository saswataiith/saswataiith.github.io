# Group portraits

Portraits identify the people named in `_data/group.json`. That file records each original image URL and its institutional or research-group source page. Retrieved 22 September 2026. Photos remain the property of their respective owners and are not relicensed under the software license.

Membership and collaborator lists were supplied by Saswata Bhattacharya. Initials are used when a portrait could not be verified or retrieved. Do not replace them with a same-name search result without confirming identity. No private contact information is included.

Edit names, notes, profile links and photo sources in `_data/group.json`; layout is `_pages/group.html`. Use a local `image` path only after verifying the photo.
