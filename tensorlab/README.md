# TensorLab interactive book

Public book: https://saswataiith.github.io/tensorlab/

The self-contained `index.html` contains the eight chapters, interactive figures,
styles and JavaScript. Open it in a browser to use it offline, or edit it in VS Code.
This is the existing interactive book, now served by this website's GitHub Pages deployment.

The separate heat, mass and momentum Transport Laboratory is maintained at
https://github.com/saswataiith/transport-phenomena-course.
