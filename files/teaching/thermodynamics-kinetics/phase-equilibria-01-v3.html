2. A self-contained two-phase binary¶

At fixed temperature $T$ and pressure, let $x=n_B/(n_A+n_B)$ and $g=G/(n_A+n_B)$, in J mol$^{-1}$. There are two ideal-solution phases, solid $\alpha$ and liquid $L$, with the same composition variable and consistent pure-component references:

Phase $g_A^0$ (J mol$^{-1}$) $g_B^0$ (J mol$^{-1}$)
$\alpha$ 0 12000
$L$ 8000 0

$$g^\phi(x,T)=(1-x)g_A^{0,\phi}+xg_B^{0,\phi} +RT[(1-x)\ln(1-x)+x\ln x].$$

The reference energies are intentionally constant with temperature for this small teaching model. A prefers $\alpha$, B prefers $L$; configurational entropy favors mixing. We neglect interfaces, elasticity, finite-size effects, kinetics and all other phases. Phase fractions below are mole fractions of material in each phase, not mass or volume fractions.

Use $0\ln0=0$ for energy at pure endpoints. Chemical potentials have logarithmic limits there, so tangents are evaluated only for $0<x<1$. Each branch is convex: $g''=RT/[x(1-x)]>0$. Two-phase equilibrium here arises from two different branches, not a spinodal instability of one branch.

Reference convention in this first calculation: these four constants share one reference for A and one for B across both phases; they are not a table of SER data. The zeros at pure A in solid and pure B in liquid are a convenient choice at the demonstration temperature. They do not authorize separately zeroing every phase's endmembers. Section 6 constructs explicit SER functions and converts between references. The temperature sweep of these frozen constants is only an entropy sensitivity experiment, not a liquid–solid phase diagram.

# Student controls: J/mol, K, and dimensionless mole fractions.
R = 8.314462618
T = 800.0
z = 0.40                 # overall B mole fraction
x_probe = 0.35           # composition for the single-phase tangent
refs = {"alpha": (0.0, 12000.0), "liquid": (8000.0, 0.0)}


def g(x, T, phase):
    x = np.asarray(x, dtype=float)
    if T <= 0 or np.any((x < 0) | (x > 1)):
        raise ValueError("Require T > 0 and 0 <= x <= 1.")
    a, b = refs[phase]
    return (1-x)*a + x*b + R*T*(xlogy(x, x) + xlogy(1-x, 1-x))


def dg(x, T, phase):
    x = np.asarray(x, dtype=float)
    if T <= 0 or np.any((x <= 0) | (x >= 1)):
        raise ValueError("Tangents require T > 0 and 0 < x < 1.")
    a, b = refs[phase]
    return b-a + R*T*np.log(x/(1-x))


def mu(x, T, phase):
    slope = dg(x, T, phase)
    return g(x, T, phase)-x*slope, g(x, T, phase)+(1-x)*slope

x = np.linspace(0, 1, 1001)
colors = {"alpha": "#1665a7", "liquid": "#bb4b25"}

3. The tangent tells us both chemical potentials¶

At fixed $T,P$, $G=ng(x)$ with $n=n_A+n_B$. Differentiating with respect to each component amount gives $$\mu_A=\left(\frac{\partial G}{\partial n_A}\right)_{T,P,n_B}=g-xg',\qquad \mu_B=\left(\frac{\partial G}{\partial n_B}\right)_{T,P,n_A}=g+(1-x)g'.$$ Thus $g'=\mu_B-\mu_A$, not either individual chemical potential. The tangent through $x_0$ is $$\ell(x)=g(x_0)+g'(x_0)(x-x_0)=(1-x)\mu_A(x_0)+x\mu_B(x_0).$$ Its extrapolated values at $x=0$ and $x=1$ give $\mu_A$ and $\mu_B$. These are not generally the pure-component energies.

Expected plot: one convex $\alpha$ curve and its tangent, touching at $x=0.35$. The left and right tangent intercepts are explicitly marked. Moving $x_0$ changes both intercepts.

Both vertical axes use exactly the same energy scale. The left axis is at $x_B=0$ and the right at $x_B=1$; the colored points are the tangent intercepts, not the endmember energies.

4. A common tangent enforces equilibrium¶

For coexisting compositions $x_\alpha,x_L$, $$\mu_A^\alpha(x_\alpha)=\mu_A^L(x_L),\qquad \mu_B^\alpha(x_\alpha)=\mu_B^L(x_L).$$ Equivalently, the tangents have the same slope and intercept: $$g_\alpha'(x_\alpha)=g_L'(x_L)=m,\quad g_\alpha(x_\alpha)-mx_\alpha=g_L(x_L)-mx_L=b.$$ Parallel tangents alone are insufficient. Also require a supporting line below all allowed energy branches; otherwise a stationary construction need not be globally stable.

For a trial slope $m$, our ideal-solution formula can be inverted: $$x_\phi(m)=\frac{1}{1+\exp[(g_B^{0,\phi}-g_A^{0,\phi}-m)/(RT)]}.$$ We vary $m$ until the two tangent intercepts coincide. brentq is a bracketed scalar root solver. expit and logaddexp evaluate the expressions without unnecessary exponential overflow. This inversion is specific to the ideal model, not a universal CALPHAD solver.

def coexistence(T):
    # Guard the teaching range against endpoint roundoff at extreme T.
    if not 200 <= T <= 3000:
        raise ValueError("Use 200 <= T <= 3000 K for this laboratory.")

    def composition(m, phase):
        a, b = refs[phase]
        return expit((m-(b-a))/(R*T))

    def intercept(m, phase):
        a, b = refs[phase]
        return a-R*T*np.logaddexp(0, (m-(b-a))/(R*T))

    def residual(m):
        return intercept(m, "alpha")-intercept(m, "liquid")

    m = brentq(residual, -200000.0, 200000.0, xtol=1e-9)
    xa, xb = composition(m, "alpha"), composition(m, "liquid")
    if not 0 < xa < xb < 1:
        raise ValueError("This lab assumes alpha is A-rich and liquid is B-rich.")
    return xa, xb, m, intercept(m, "alpha")

5. Equilibrium amounts: the lever rule¶

Let $z$ be the overall B mole fraction, with $f_\alpha+f_L=1$. Conservation requires $$z=f_\alpha x_\alpha+f_L x_L.$$ For $x_\alpha<z<x_L$, $$f_L=\frac{z-x_\alpha}{x_L-x_\alpha},\qquad f_\alpha=\frac{x_L-z}{x_L-x_\alpha},\quad g_{\rm eq}(z)=f_\alpha g_\alpha(x_\alpha)+f_L g_L(x_L).$$ Outside this interval the stable state is a single phase at composition $z$; do not extrapolate the lever rule to negative fractions. At a boundary the amount of the incipient phase is zero. The common tangent extended outside the interval is not an attainable mixture of these two endpoint compositions.

Expected plot: two convex curves, a dashed supporting line and a thick lower equilibrium envelope. Inside the tie line the envelope is straight. The marked energy saving at $z$ compares equilibrium to the lower homogeneous branch at the same overall composition. It is an energy per mole, not a kinetic rate or activation barrier.

def equilibrium(z, T):
    z = np.asarray(z, dtype=float)
    if np.any((z < 0) | (z > 1)):
        raise ValueError("Require 0 <= z <= 1.")
    xa, xb, m, b = coexistence(T)
    fb = np.clip((z-xa)/(xb-xa), 0, 1)
    fa = 1-fb
    geq = np.where(z <= xa, g(z,T,"alpha"),
           np.where(z >= xb, g(z,T,"liquid"), b+m*z))
    return fa, fb, geq

6. Explicit SER example: solid α and liquid for each species¶

The reference belongs to the species, not to the phase being evaluated. A and B may have different stable crystal structures in a real database. For this fictional example, both stable elemental phases at $T_r=298.15$ K and $P_r=1$ bar are called α.

SER (standard/stable element reference) conventionally uses the enthalpy $H_i^{\rm SER}(T_r,P_r)$ of each element in that state. Write the tabulated quantity as $$\bar g_i^{0,\phi}(T)=G_i^{0,\phi}(T,P_r)-H_i^{\rm SER}(T_r,P_r),\quad \phi\in\{\alpha,L\}.$$ The same $H_A^{\rm SER}$ is used for A in α and in liquid, and the same $H_B^{\rm SER}$ for B in both phases. The bars emphasize the energy reference; our earlier $g$ and $\mu$ are likewise always reference-dependent values.

SER does not mean $G_i^{\rm SER}(298.15)=0$. At the reference temperature, $$\bar g_i^{0,\alpha}(T_r)=-T_r S_i^\alpha(T_r),$$ which is generally nonzero. The entropy at 298.15 K is not arbitrarily erased. The reference state is fixed; it does not switch to liquid when the calculation temperature crosses the melting point.

Build original unary functions, rather than copy a database¶

Use constant heat capacities, with hypothetical parameters:

Species $C_p^\alpha=C_p^L$ (J mol$^{-1}$ K$^{-1}$) $S_i^\alpha(T_r)$ (J mol$^{-1}$ K$^{-1}$) $T_{m,i}$ (K) $\Delta H_{fus,i}$ (J mol$^{-1}$)
A 25 30 1400 $56000/3$
B 30 40 600 36000

Integrating $C_p$ from $T_r$ and retaining the entropy term gives $$\bar g_i^{0,\alpha}(T)=C_{p,i}(T-T_r)-T\left[S_i^\alpha(T_r)+C_{p,i}\ln(T/T_r)\right].$$ With equal solid/liquid heat capacities, the fusion difference is $$\Delta g_{fus,i}(T)=\Delta H_{fus,i}\left(1-\frac{T}{T_{m,i}}\right),\qquad \bar g_i^{0,L}(T)=\bar g_i^{0,\alpha}(T)+\Delta g_{fus,i}(T).$$ Both phases of a species meet at its melting temperature. Above it, that species' liquid is lower in Gibbs energy. These functions are only an instructional constant-$C_p$ model, not a fit for real A or B or a low-temperature extrapolation to 0 K.

At 800 K the fusion differences are +8000 J/mol for A and −12000 J/mol for B. The four original constants can therefore be recovered by subtracting one shared reference per species: $r_A=\bar g_A^{0,\alpha}(800)$, $r_B=\bar g_B^{0,L}(800)$. This connects the earlier illustrative table to a consistent SER construction.

T_ref = 298.15
unary = {"A": {"Cp": 25., "S_ref": 30., "Tm": 1400., "H_fus": 56000/3},
         "B": {"Cp": 30., "S_ref": 40., "Tm": 600., "H_fus": 36000.}}


def ser_endmembers(temp):
    """G_i^phase(T) - H_i^SER(298.15 K), J/mol; fixed pressure 1 bar."""
    if temp <= 0:
        raise ValueError("Temperature must be positive.")
    solid, liquid = [], []
    for element in ["A", "B"]:
        u = unary[element]
        gs = u["Cp"]*(temp-T_ref)-temp*(u["S_ref"]+u["Cp"]*np.log(temp/T_ref))
        fusion = u["H_fus"]*(1-temp/u["Tm"])
        solid.append(gs)
        liquid.append(gs+fusion)
    return {"alpha": tuple(solid), "liquid": tuple(liquid)}

T_ser = 800.0             # Independent fixed temperature for the reference comparison.
ser_refs = ser_endmembers(T_ser)
solid_reference = np.array(ser_refs["alpha"])
solid_reduced = {phase: tuple(np.array(values)-solid_reference)
                 for phase, values in ser_refs.items()}

The same equilibrium in two reference conventions¶

For any chosen species references $r_A(T)$ and $r_B(T)$, applied identically to every phase, $$\widetilde g^\phi(x,T)=\bar g^\phi(x,T)-[(1-x)r_A(T)+xr_B(T)].$$ Then $\widetilde\mu_A^\phi=\bar\mu_A^\phi-r_A$ and $\widetilde\mu_B^\phi=\bar\mu_B^\phi-r_B$. Since each species receives the same shift in each phase, equality of chemical potentials and the equilibrium phase amounts are unchanged. A temperature-dependent reference is acceptable for this fixed-$T$ equilibrium comparison; derivatives used for entropy and enthalpy must also include the reference's temperature dependence.

In the right-hand plot choose $r_i(T)=\bar g_i^{0,\alpha}(T)$. This makes both pure-solid endmembers zero, while retaining the liquid–solid differences. This is a common solid-Gibbs reference at the calculation temperature, not the SER enthalpy convention.

Expected plots: the left uses SER-referenced energies; the right uses pure-solid Gibbs references. Their slopes and intercepts differ, but both tangency compositions and phase fractions agree. Both left/right vertical axes show the intercepts on identical scales within each panel. Numerical scales need not match between panels because the references differ.

If instead we subtract each phase's own pure endmembers, both ideal curves collapse to the same $RT[x\ln x+(1-x)\ln(1-x)]$. That is useful for displaying mixing energies, but discards the fusion differences and cannot be used alone to determine solid–liquid equilibrium.

7. Three-phase equilibrium: why a binary eutectic is invariant¶

At fixed pressure the Gibbs phase rule is $$F=C-P+1.$$ For a binary system with three phases ($\alpha+L+\beta$), $F=2-3+1=0$: the equilibrium temperature and the three phase compositions are fixed. A change in temperature destroys three-phase coexistence. Pressure is held at 1 bar here; without that constraint the full rule would give $F=C-P+2=1$.

Use a separate illustrative quadratic model, not an extrapolation of the earlier ideal/SER model. All phases share the same species reference convention. Let $T_E=1000$ K, $$g^\alpha=K(x-0.15)^2,\quad g^\beta=K(x-0.85)^2,\quad g^L=K(x-0.50)^2-\Delta s(T-T_E),$$ where $K=20000$ J/mol and $\Delta s=20$ J/(mol K). These are local teaching approximations, not realistic pure-element limits or assessed alloy data. No entropy of ideal mixing is added to these parabolas.

At $T_E$, one horizontal supporting tangent touches all three curves: $$x_\alpha=0.15,\quad x_L=0.50,\quad x_\beta=0.85,\qquad \mu_A^\alpha=\mu_A^L=\mu_A^\beta=0,\quad \mu_B^\alpha=\mu_B^L=\mu_B^\beta=0.$$ The zero values are a convenient shared energy reference, not a requirement for an invariant. Adding a common affine reference term would tilt this same three-contact tangent and leave the compositions unchanged.

Expected plots: below $T_E$, the stable common tangent connects α and β; at $T_E$ it also touches liquid; above $T_E$, separate α–L and L–β tangents occur, with a single-liquid interval between them. Each panel has identical energy scales on its left/right axes. At $T_E$ the colored endpoint markers identify the common chemical potentials.

For parabolas $g_i=K(x-c_i)^2+h_i$, the pair-tangent slope is $m=(h_j-h_i)/(c_j-c_i)$ and the contact compositions are $x_i=c_i+m/(2K)$, $x_j=c_j+m/(2K)$. A candidate is kept only if its contacts are in [0,1] and it lies below all three branches.

from itertools import combinations
TE, curvature, delta_s = 1000., 20000., 20.
centers = {"alpha": .15, "liquid": .50, "beta": .85}
three_colors = {"alpha": "#1665a7", "liquid": "#bb4b25", "beta": "#7649a5"}


def height(phase, temp):
    return -delta_s*(temp-TE) if phase == "liquid" else 0.


def g_three(xx, temp, phase):
    return curvature*(np.asarray(xx)-centers[phase])**2+height(phase,temp)


def stable_three_tangents(temp):
    tangents = []
    for pi,pj in combinations(centers,2):
        ci,cj = centers[pi],centers[pj]
        m = (height(pj,temp)-height(pi,temp))/(cj-ci)
        xi,xj = ci+m/(2*curvature),cj+m/(2*curvature)
        b = float(g_three(xi,temp,pi)-m*xi)
        if not (0 <= xi <= 1 and 0 <= xj <= 1):
            continue
        # Exact constrained minimum of each quadratic minus the tangent.
        gaps = [g_three(np.clip(ck+m/(2*curvature),0,1),temp,pk)
                -m*np.clip(ck+m/(2*curvature),0,1)-b
                for pk,ck in centers.items()]
        if min(gaps) >= -1e-8:
            tangents.append((pi,pj,xi,xj,m,b))
    return tangents

Invariant compositions do not uniquely fix the phase amounts¶

The phase rule counts intensive degrees of freedom, not the amounts of material in the phases. At $T_E$ with overall composition $z$, $$f_\alpha+f_L+f_\beta=1,\qquad 0.15f_\alpha+0.50f_L+0.85f_\beta=z.$$ There are only two independent equations for three unknown fractions. Choose $\lambda=f_L$; then $$f_\beta=\frac{z-0.15-0.35\lambda}{0.70},\qquad f_\alpha=1-\lambda-f_\beta.$$ All nonnegative solutions have the same equilibrium Gibbs energy on the common tangent. An additional condition, such as total enthalpy during a thermal arrest, can fix the amounts. $F=0$ does not remove this freedom in phase amounts.

At $z=0.40$, $0\le f_L\le5/7$. Interior values give all three phases; the limiting values have one absent phase. The endpoint states are limits of the three-phase assemblage, not states with three positive fractions.

The eutectic reaction is $L(0.50)\rightleftharpoons\alpha(0.15)+\beta(0.85)$. For one mole of liquid at its eutectic composition, complete freezing gives 0.5 mol α and 0.5 mol β. At $T_E$, partial freezing can coexist with the remaining liquid without changing any of these phase compositions.

An independent analytic result follows directly from the ideal-solution chemical potentials. Define $$K_A=\exp[(g_A^{0,\alpha}-g_A^{0,L})/(RT)],\quad K_B=\exp[(g_B^{0,\alpha}-g_B^{0,L})/(RT)].$$ Equality of potentials gives $1-x_L=K_A(1-x_\alpha)$ and $x_L=K_Bx_\alpha$, hence $$x_\alpha=\frac{1-K_A}{K_B-K_A},\qquad x_L=K_Bx_\alpha.$$ This provides a check independent of the slope-root construction.

Interpretation of solutions.

  1. The slope is $\mu_B-\mu_A$; the intercept supplies the missing information.

  2. At fixed $T,P$, the two coexisting compositions and chemical potentials stay fixed as $z$ changes inside the tie line. Fractions change to conserve material. At $z=0.05$ only $\alpha$ is stable; at $z=0.90$ only $L$ is stable, each at composition $z$.

  3. The curves cross at $x=0.4$, but their slopes differ by 20000 J/mol. Separating into different compositions lowers the total Gibbs energy. Equality of both chemical potentials is the equilibrium criterion.

  4. The interval narrows with increasing $T$ over the stated range. Mixing becomes more favorable. The fixed reference energies are a teaching simplification: do not infer a real alloy phase diagram or a finite critical temperature from this model.

  5. A common affine shift changes neither compositions nor fractions. It shifts $m$ by $d$, $\mu_A$ by $c$, and $\mu_B$ by $c+d$. Both homogeneous and equilibrium energy at $z$ shift by $c+dz$, so the energy saving is unchanged.

  6. The SER example's printed table gives the four values. At 298.15 K, the solid values are −8944.5 J/mol (A) and −11926 J/mol (B), because $G-H^{SER}=-T_rS(T_r)$. Subtracting each species' solid Gibbs energy from both phases gives α: (0, 0), liquid: (+8000, −12000) J/mol at 800 K. A is below its 1400 K melting point and favors solid; B is above its 600 K melting point and favors liquid. Subtracting different phase-specific references would remove these differences and destroy the equilibrium comparison. The numerical check above confirms identical compositions/fractions and the correct chemical-potential shifts.

  7. At fixed pressure, $F=2-3+1=0$. With $f_L=0.20$, $(f_\alpha,f_L,f_\beta)=(0.542857,0.20,0.257143)$; with $f_L=0.60$, they are $(0.342857,0.60,0.057143)$. Both sum to one and give $z=0.40$. Phase amounts are not counted by $F$. Total enthalpy (with known phase enthalpies), for example, supplies a third independent balance. Below $T_E$ liquid lies above the α–β tangent; above $T_E$ it lies below that line, so no single tangent can support all three phases.
