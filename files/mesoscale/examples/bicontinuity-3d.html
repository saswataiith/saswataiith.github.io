Why x, y and z?

The periodic domain is a box with opposite faces identified. Following a closed loop in unwrapped coordinates gives a winding vector (wₓ,wᵧ,w_z): how many box lengths it advances along each coordinate. The earlier x, y and z labels abbreviated (1,0,0), (0,1,0) and (0,0,1). Curved, branching paths can have these windings; the labels never meant straight channels or motion confined to an axis.

Interconnectivity is established by the full graph measurement: all thresholded red voxels belong to one component, and all blue voxels belong to another. Independent wrapping loops establish periodic percolation in all three directions. Each displayed branched witness also has one component and winding rank three; every edge is checked against the original phase. The two phase networks are mutually disjoint.

The display is a connected witness subgraph, not an exhaustive skeleton or a longest path. A walk can repeat loops indefinitely, so it has no longest length. A longest simple path forbids repeated voxels and is a separate difficult optimization problem; its length does not prove connectivity of all voxels.

The neutral c = 0.5 interface is shared by both phases, extracted from the full 256³ field without box-face caps, and simplified only for display. Key, fill and rim lighting and smooth normals reveal its shape. Network paths use full-resolution voxel centres. Opposite-face links are split visibly at the boundary, never drawn as shortcuts across the box. Hide the interface to inspect the two branched networks clearly.

How do we measure connectivity and morphology?

For connectivity, label face-sharing voxels with opposite faces identified. Count components and the fraction of each phase in its largest component. To measure periodic percolation, lift steps into unwrapped coordinates: returning to the same voxel with a displacement of one or more box lengths produces a winding vector. Three independent vectors give winding rank three. Merely touching opposite faces is insufficient.

In 2D, trace the c = 0.5 contours, joining periodic seam segments before deciding whether a contour closes. In 3D, the interface is a surface. Surface area and curvature describe its geometry; components, tunnels and cavities describe its topology. For a closed, connected, orientable surface, Euler characteristic is 2 − 2g, where g is its genus. This formula must not be applied directly to the cropped, simplified display mesh: periodic seams need identification and the surface must be checked for manifold defects.

Minkowski functionals summarize volume, interface area, integrated mean curvature and Euler characteristic (with convention-dependent normalization). Euler characteristic combines topology into one number; it does not separately establish component counts or winding. The historical Fiałkowski–Aksimentiev–Hołyst work studies these morphological measures. This example currently reports component counts and winding; it has not measured genus, tunnel counts, cavity counts or integrated curvature.

Reproduce and learn from the example

Dimensionless Cahn–Hilliard: ∂c/∂t = M∇²μ, μ = f′(c) − κ∇²c; f = Ac²(1−c)². A = M = κ = 1, 256³ grid, spacing 0.25 (box length 64), Δt = 0.5, 400 steps, final time 200. Seed 20261005; Gaussian initial noise of standard deviation 0.01, with its sample mean removed from c = 0.5.

The stabilized semi-implicit Fourier method treats f′ explicitly and the gradient term implicitly, with stabilization S = 2 and without dealiasing. The zero Fourier mode conserves mass. Energy is checked every 20 steps in this run; this is not a proof of unconditional stability or convergence.

Download the two Python scripts below to one folder. The generator writes composition.npy (unclipped float32 256³ array, axes x,y,z; 64 MiB), report.json (parameters, mass, energy and periodic connectivity), and viewer.json (display surfaces and connected branched witness graphs, with independent wrapping loops at threshold 0.5). The report records library versions and simulation parameters. Generation requires a few GB of memory and can take several minutes or longer. It is run only once: afterwards both viewers load the fixed saved surfaces and routes. Loading the display mesh can take longer on older devices. Native VPython opens its display in a browser and requires a running Python process.

To run this website viewer locally, keep the website directory structure and serve its root using python -m http.server 8000. Open http://localhost:8000/files/mesoscale/examples/bicontinuity-3d.html. Internet access is needed for the GlowScript libraries.

Worked solutions and self-checks: the generator asserts finite values, mass drift below 10⁻¹⁰, rank-three winding at all three thresholds, and phase membership, six-neighbour steps, one component and rank-three winding of each displayed witness network. Try another seed or coarsening time and compare the measured topology before calling it bicontinuous.
