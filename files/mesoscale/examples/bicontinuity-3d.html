Magenta: path already executed. Green: turtle. Grey: optional planned route. The magenta trail grows only as the turtle moves and remains visible when paused.

Rotate: right-drag or Ctrl-drag. Zoom: mouse wheel or pinch. Positions and speed are in voxel units; one voxel spans 0.25 dimensionless length units. The turtle’s centre follows face-sharing voxel steps. Its enlarged body is a marker, not a resolved physical particle. At a periodic face it reappears at the corresponding point on the opposite face; no line is drawn across the intervening box.

The displayed surface is the c = 0.5 isosurface extracted from the full 256³ field, with no artificial box-face caps. It is simplified to 60,000 triangles for responsiveness. Both phases share this interface; its colour and normal orientation follow the selected phase. Directional key, fill and rim lighting, ambient light and smooth normals reveal its shape. This is a visual approximation; connectivity and the turtle’s centre route are checked on every original voxel. The thick magenta trail records only the path already executed; it stops at a periodic face and resumes at the paired face. The optional grey line previews the complete route. Hide the interface or lower its opacity to inspect the full trail clearly. Routes start near the centre and travel through phase cores (red c ≥ 0.75; blue c ≤ 0.25), with at least two voxel layers of phase clearance. They stay away from the other two pairs of box faces; only the selected winding direction crosses a periodic face. These core thresholds select comfortable routes; the phase definition remains c = 0.5.

Each selected loop winds once in its named direction and zero times in the others. The turtle demonstrates six verified routes; it does not visit every voxel.

Reproduce and learn from the example

Dimensionless Cahn–Hilliard: ∂c/∂t = M∇²μ, μ = f′(c) − κ∇²c; f = Ac²(1−c)². A = M = κ = 1, 256³ grid, spacing 0.25 (box length 64), Δt = 0.5, 400 steps, final time 200. Seed 20261005; Gaussian initial noise of standard deviation 0.01, with its sample mean removed from c = 0.5.

The stabilized semi-implicit Fourier method treats f′ explicitly and the gradient term implicitly, with stabilization S = 2 and without dealiasing. The zero Fourier mode conserves mass. Energy is checked every 20 steps in this run; this is not a proof of unconditional stability or convergence.

Download the two Python scripts below to one folder. The generator writes composition.npy (unclipped float32 256³ array, axes x,y,z; 64 MiB), report.json (parameters, mass, energy and periodic connectivity), and viewer.json (display surfaces and six full-resolution closed routes at threshold 0.5). The report records library versions and simulation parameters. Generation requires a few GB of memory and can take several minutes or longer. It is run only once: afterwards both viewers load the fixed saved surfaces and routes. Loading the display mesh can take longer on older devices. Native VPython opens its display in a browser and requires a running Python process.

To run this website viewer locally, keep the website directory structure and serve its root using python -m http.server 8000. Open http://localhost:8000/files/mesoscale/examples/bicontinuity-3d.html. Internet access is needed for the GlowScript libraries.

Worked solutions and self-checks: the generator asserts finite values, mass drift below 10⁻¹⁰, rank-three winding at all three thresholds, and every route’s phase membership, six-neighbour steps and exact winding. Try another seed or coarsening time and compare the measured topology before calling it bicontinuous.
