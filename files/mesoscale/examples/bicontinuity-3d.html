Reproduce and learn from the example

Dimensionless Cahn–Hilliard: ∂c/∂t = M∇²μ, μ = f′(c) − κ∇²c; f = Ac²(1−c)². A = M = κ = 1, spacing 1, 24³ grid, Δt = 0.1, 1200 steps, final time 120. Seed 20261005; Gaussian initial noise of standard deviation 0.01, with its sample mean removed from c = 0.5.

The semi-implicit Fourier method treats f′ explicitly and the gradient term implicitly, without dealiasing. The zero Fourier mode conserves mass. Energy decreased at every recorded step in this run; this is not a proof of unconditional stability or convergence.

Download the two Python scripts below to one folder. The generator writes composition.npy (unclipped float64 array, axes x,y,z), report.json (parameters, mass, energy and periodic connectivity), and viewer.json (voxel coordinates and six closed routes at threshold 0.5). The saved simulation used NumPy 2.3.5; regeneration with that version reproduces the saved field and routes byte for byte. Typical generation takes seconds; drawing thousands of voxels can take longer on older devices. Native VPython opens its display in a browser and requires a running Python process.

To run this website viewer locally, keep the website directory structure and serve its root using python -m http.server 8000. Open http://localhost:8000/files/mesoscale/examples/bicontinuity-3d.html. Internet access is needed for the GlowScript libraries.

Worked solutions and self-checks: the generator asserts finite values, mass drift below 10⁻¹², one component per phase at all three thresholds, rank-three winding, and every route’s phase membership, six-neighbour steps and exact winding. Try another seed or coarsening time and compare the measured topology before calling it bicontinuous.
