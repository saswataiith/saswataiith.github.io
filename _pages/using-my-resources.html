TEACHING AND RESEARCH

Using my resources

If you use my notes, codes, figures or interactive demonstrations in your teaching, research or presentations, please acknowledge the source and include a link to the relevant page on this website.

Unless a resource states otherwise, the original teaching text, notes and figures that I own on this website are available under the Creative Commons Attribution 4.0 International license (CC BY 4.0). You may copy, share and adapt this material, including for commercial use. Credit me, link to the source and the license, and indicate any changes you make.

For example: “Adapted from [resource title] by Saswata Bhattacharyya, [page link], CC BY 4.0. Changes: [brief description].”

Using my code. I permit free noncommercial teaching, learning and demonstrations with acknowledgment. Research (including academic research) and commercial use require my explicit written permission. Earlier MIT and GPL releases retain their existing permissions. Read the code-use terms. Request permission at saswata_at_msme.iith.ac.in.

This policy covers all my original codes hosted on this website: Julia, Python/NumPy, C, notebook code cells and browser demonstrations, including downloads. The elasticity laboratory and elasticity solvers retain their existing GPL licenses. Libraries and code credited to others retain their own terms. See the code license scope. The Creative Commons license above does not apply to software. These restrictions make the current code source available; they are not an open-source license.

Research code: historical C model · Julia thesis model · embedded-particle model.

Published papers, students’ thesis material, jointly owned material, institute logos and other material credited to others are not covered by this license. Follow their stated terms, cite the original paper where applicable, and retain the authors’ names.
