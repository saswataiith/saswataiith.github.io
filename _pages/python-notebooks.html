MY PYTHON TEACHING CODES

How I develop a calculation
in notebook cells.

I build each calculation in notebook cells. I explain the quantities, write a small part, run it and compare the result with a stated check before continuing. I keep the complete command-line programs available, but the notebooks are the main learning route.

Start with the portrait

In the color portrait lesson, I first read three color channels and check a pixel shuffle. I then define an energy, verify that its minimum is zero, compare one Allen–Cahn and Cahn–Hilliard evolution, and test mean drift. Only after these checks do I save the full animation.

What I checked

I executed all 17 new notebooks from fresh kernels. The portrait, 2D spinodal, diffusion and random-walk notebooks run their original full calculations. Monte Carlo runs short 16² checks. The 3D lessons run small exact-mask checks; their full-volume runs remain optional. The native VPython lessons check the saved route data by default; their scene and event loop require an interactive local Jupyter session. These execution checks do not claim numerical convergence.
