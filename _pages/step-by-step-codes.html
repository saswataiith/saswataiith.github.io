MY TEACHING CODES

Develop the code
one step at a time.

I first write a small part of a calculation and test it. Once I understand the result, I add the next part. These lessons follow that approach rather than beginning with a complete program and asking students to understand everything at once.

How to work through a lesson

  1. Read what I want to calculate and how the quantities are defined.
  2. Run the small code cell or compile the C checkpoint.
  3. Compare the result with the stated check. If it fails, inspect this part before adding anything else.
  4. Continue to the next part. The complete program remains available for comparison.

The Python and Julia notebooks show the calculations directly. Run their cells in order. Each C checkpoint is a complete program that I compile and test before adding the next part.
