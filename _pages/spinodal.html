1. The model

Let c be a conserved, composition-like order parameter, with equilibrium bulk values near −1 and +1. It is dimensionless and is not directly an alloy mole fraction. We use a double-well bulk free energy and a gradient penalty on a periodic square.

\[\begin{aligned}F&=\int\left[\frac{(c^2-1)^2}{4}+\frac\kappa2|\nabla c|^2\right]dA\\\mu&=c^3-c-\kappa\nabla^2c\\\frac{\partial c}{\partial t}&=M\nabla^2\mu\end{aligned}\]

In the example, M = 1, κ = 1 and the grid spacing is 1. A small random perturbation with mean zero seeds the unstable state. The continuous equation conserves mean c and dissipates free energy under periodic boundary conditions.

2. Run the example

python -m pip install numpy pillow
python spinodal_demo.py

The script writes three images, a final field array and a diagnostic CSV into spinodal_output/. It uses a 128 × 128 grid, time step 0.2, 1,600 steps and random seed 42. The images shown here were generated with that script.

Color scale: blue = c near −1; cyan = −0.5; green = 0; yellow = 0.5; red = +1. The scale is fixed across all snapshots.

3. Understand the update

The periodic domain allows spatial derivatives to be evaluated in Fourier space. We treat the gradient penalty implicitly and the derivative of the bulk energy explicitly:

\[\widehat c^{\,n+1}=\frac{\widehat c^{\,n}-\Delta t\,|\mathbf k|^2\mathcal F[(c^n)^3-c^n]}{1+\Delta t\,\kappa|\mathbf k|^4}\]

The zero wave-number mode is unchanged, which conserves the mean. The bulk term is nonlinear; evaluating it on a finite grid introduces discretization error, including aliasing. This small example does not use de-aliasing.

Do not confuse stability with accuracy.

This semi-implicit scheme is not unconditionally energy stable. If a time step produces an energy increase, refine it and inspect the trajectory. Monotone energy alone does not establish temporal or spatial convergence.

4. Check before interpreting

  1. Conservation: compare the initial and final mean. Drift should remain near floating-point round-off.
  2. Energy: plot energy density against time. The supplied diagnostic file samples every ten steps; inspect more frequently if necessary.
  3. Time-step sensitivity: halve Δt and double the number of steps to compare at the same final time.
  4. Grid convergence: refine the spacing while preserving the physical domain size. Simply increasing n with spacing fixed also enlarges the domain, so it is not a pure grid refinement.
  5. Initial conditions: compare statistical measures across random seeds; do not expect identical domain layouts.

5. Go further

Start with the Spinodal repository and the MicroSim documentation to connect this model with larger codes. Adding elastic energy, composition-dependent mobility or multiple components changes the physical problem and its numerical requirements.
